# RESEARCH_SYNTHESIS

Исследовательские ориентиры. Источники **принципов**, не объектов копирования. Ничего не копируется один в один. Для каждого продукта: что берём / чего не берём / влияние на Alfa Trade Academy.

---

## Duolingo

**Берём:**
- guided learning path — единый ведущий путь;
- один следующий шаг в каждый момент;
- небольшие учебные блоки;
- сохранение завершённого прогресса;
- встроенное повторение;
- возврат к пройденным уровням;
- кнопка возврата к текущей позиции на длинном пути.

**Не берём:**
- детскую стилистику;
- чрезмерную мультяшность;
- агрессивное наказание за потерю streak.

**Влияние на ATA:**
- Горизонтальный путь L1–100 с автоцентрированием текущего уровня и кнопкой «К текущему уровню».
- «Серия обучения» без красного наказания; после пропуска — «Продолжим с текущего этапа», лучший результат сохраняется.
- Главная всегда предъявляет один primary CTA (см. приоритет в `PAGE_INVENTORY.md`).
- Взрослая премиальная подача вместо игрового детского тона.

## Brilliant

**Берём:**
- learning by doing;
- короткое объяснение и немедленное применение;
- пошаговые задачи;
- визуальные сценарии;
- проверку понимания.

**Не берём:**
- академическую перегруженность;
- длинные текстовые лонгриды без действия.

**Влияние на ATA:**
- Урок = короткая цель → видео → немедленное применение (связанный tool) → тест.
- Тесты допускают scenario-вопросы и chart images; правильным ответом может быть «отказаться от сделки».
- Practical-задания сразу после теории (checklist, разметка графиков, Risk Plan и т.д.).

---

## TradingView

**Берём:**
- качественную плотность профессионального интерфейса;
- хорошие drawing tools;
- ясные toolbars;
- сохранение рабочего контекста;
- постепенное раскрытие сложности (progressive disclosure).

**Не берём:**
- выдачу новичку полноценного терминала со множеством controls;
- live-торговый интерфейс.

**Влияние на ATA:**
- Chart Markup Tool (L20): line/zone/rectangle/arrow/text/support-resistance/trend/invalidation, undo/redo, layers, versions — но по **uploaded screenshot**, не live chart.
- Инструменты открываются постепенно (L10→L100); сложность растёт с рангом.
- Pro Workspace (L100) — плотная, но **не** торговый терминал; собирается из уже открытых виджетов.

## Linear

**Берём:**
- системность;
- спокойную премиальность;
- типографическую дисциплину;
- скорость;
- минимальный визуальный шум;
- quality-first;
- реализацию маленькими этапами.

**Не берём:**
- ничего специфичного для issue-tracker домена.

**Влияние на ATA:**
- Functional mode: спокойные поверхности, строгая типографика, быстрые переходы 140–240 ms.
- Дисциплина токенов и компонентов (`DESIGN_SYSTEM.md`, `COMPONENT_INVENTORY.md`).
- Пофазная реализация D0–D9 с чёткими acceptance и stop conditions.

---

## Pocket Option

**Используем как ориентир:**
- по знакомому аудитории характеру палитры;
- по dark surfaces;
- по taxonomy образовательного контента;
- по публичной структуре статей;
- по готовности к польской локализации.

**Не копируем:**
- trader leaderboards;
- payout tables;
- trading turnover comparisons;
- bonus casino mechanics;
- финансовые соревнования.

**Влияние на ATA:**
- Dark-only поверхности, знакомый аудитории «характер» без имитации терминала Pocket.
- Публичный News-раздел: indexable статьи, категории, автор, дата, reading time, related, SEO-метаданные, польская локализация позже, без комментариев.
- Никаких financial/profit/volume leaderboards; никаких casino-механик и наград за число сделок.
- Финансовая приватность жёстче, чем у брокера: ATA не показывает баланс вообще.
