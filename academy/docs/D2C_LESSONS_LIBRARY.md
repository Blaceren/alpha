# D2C-B — Библиотека уроков (`/lessons`)

Реализация фазы **D2C** на выбранном направлении **Concept B «Curriculum Index»**.
Baseline: `2829224` (art direction). Scope и определение: `docs/D2C_LESSONS_LIBRARY_SCOPE.md`.

---

## 1. Что построено

`/lessons` перестал быть redirect'ом и стал **страницей**: обзор учебного материала.

| Было (D2B) | Стало (D2C-B) |
|---|---|
| `/lessons` → `redirect('/lessons/level.018')` | `/lessons` — библиотека |
| «Уроки» в навигации — `aria-disabled` + «Скоро» | «Уроки» — настоящий built route с `aria-current` |

Контекстный дефолт «перейти к текущему уроку» **не потерян** — он повышен до доминирующего действия
страницы «Продолжить обучение» (DD-258). Маршруты уроков (`/lessons/level.018`, `level.019` и прочие
динамические) не тронуты; lesson state machine и session progression не менялись.

**Mobile** (<900px) — не уменьшенный desktop: индекс из 20 модулей **скрыт**, его место занимает
перенесённый из Concept A **степпер** (‹ «Модуль 04 из 20» ›) с доступом к полному списку через sheet.

Порядок на mobile: shell → `Уроки` → степпер → продолжение → содержание модуля → fixed bottom nav.

### Что перенесено из Concept A

Ровно одно и только для mobile (DD-261): компактный переключатель модуля (предыдущий / «Модуль NN из
20» / следующий) + доступ к полному списку. **Постоянная левая рейка A не перенесена.**

### Почему отклонён Concept C

Цепочка ролей «изучаю → применю → откроет» дублировала бы Главную (текущий урок + CTA + будущая
контрольная точка) и размывала бы границу с Путём: «Уроки» стали бы второй Главной. Отклонён
пользователем при выборе направления.

## 3. Архитектура

Один **presentation projector** — `src/features/lessons-library/model/lessons-library-model.ts`.
React-компоненты получают готовую модель и **не вычисляют progression business rules** (DD-262).

| Слой | Файл | Роль |
|---|---|---|
| projector | `model/lessons-library-model.ts` | curriculum + marker + session → `LessonsLibraryModel` |
| session port | `hooks/use-session-progress.ts` | `sessionStorage` через `useSyncExternalStore` |
| workspace | `components/lessons-library-workspace.tsx` | композиция + полоса продолжения |
| index | `components/library-module-index.tsx` | 20 модулей (desktop-колонка и mobile-sheet) |
| content | `components/library-module-content.tsx` | уровни выбранного модуля |
| switcher | `components/library-module-switcher.tsx` | mobile степпер + sheet |

### Переиспользовано, не скопировано

`CURRICULUM` / `getModuleByIndex` / `getModuleForLevel` (структура), `path-state` (`PathProgress`,
`moduleAggregateState`, **`moduleCompletedCount`**), `lesson-availability` (`resolveRouteAvailability`),
`lesson-session-progress`, `lesson-progress-store`, `lesson-fixtures` (длительность),
`formatThresholdUsd`, `rankLabel`, `formatDuration`, `levelCodeFor`, канонические navigation-компоненты
и токены.

**Второго набора нет:** ни названий модулей/уровней, ни thresholds, ни rewards, ни типов уроков, ни
статусов. Единственный новый словарь — `kindLabel` (§4).

### Ключевое различение

Путь называет уровень 19 «available» («следующий в очереди»), но **урок он не открывает**. Авторитет —
`resolveRouteAvailability`, и библиотека спрашивает только его. Поэтому до завершения 18 уровень 19 —
`locked` («Откроется после уровня 18»).

## 4. `kindLabel` — один владелец

До D2C подписи типов были вписаны ad hoc в компоненты (`path-detail-layer.tsx`,
`lesson-locked-screen.tsx`). D2C-A вынес это как долг: третья расходящаяся копия — вопрос времени.
Теперь словарь один — в проекторе:

`task` → «Задание» · `video-test` → «Видео-урок и тест» · `report` → «Отчёт» ·
`practical` → «Практическое задание» · `checkpoint` → «Контрольная точка».

## 5. Длительность — честно

Показывается **только там, где реально известна**. Источник — `lesson-fixtures`: `getLessonEntry(n)`
даёт `media.durationSeconds` лишь для авторенного урока. Сегодня это **ровно один уровень — 18 (8:00)**;
у остальных 99 длительности не существует, и она не выдумывается. Правило data-driven: как только
появится второй авторенный урок, его длительность появится сама.

## 6. Module URL-state

`/lessons?module=module.NN` — **обычное пользовательское состояние**, не development scenario (DD-263):

- значение — **канонический код модуля** из curriculum fixture (`module.04`), второй идентификатор не
  заводится (тест сверяет `moduleCodeFor(i) === CURRICULUM.modules[i].code` для всех 20);
- shareable и переживает reload; Back/Forward работают нативно (обычная навигация Next.js);
- неизвестный/битый код → **текущий модуль пользователя**, страница не падает, факт отражён флагом
  `isModuleFallback`;
- выбор модуля **не меняет progression**: маркер и полоса продолжения остаются прежними;
- открыть закрытый последовательностью урок нельзя ни из какого модуля.

Default selected module — **текущий модуль из общего path state**, а не хардкод `04` в React.

`/lessons` **не читает `?scenario`**. Ключ маркера — внутренний prop (`scenario="active"`), как у
`PathWorkspace`; через границу server→client уходит только он, поэтому инструментовка, которую
библиотека не рендерит (`rankLabel`, `xpLabel`, `streak`), в payload не попадает.

## 7. Session progression (интеграция D2B.1)

| Ситуация | Библиотека |
|---|---|
| до завершения 18 | 18 — текущий; 19 — «Откроется после уровня 18»; 2 из 5; CTA → `/lessons/level.018` |
| после реального завершения 18 в этой сессии | 18 — «Завершён · Пересмотреть»; 19 — текущий practical; 3 из 5; CTA «Перейти к заданию» → `/lessons/level.019` |
| hard reload той же вкладки | состояние сохраняется |
| новый browser context | исходное состояние |
| битый marker | исходное состояние, без падения |

Сессия может только **открыть** недостигнутый уровень: `effectiveProgress` идёт вперёд, пока каждый
следующий уровень отмечен завершённым, и никогда не двигает маркер назад и не даёт перепрыгнуть
(DD-256). Подделанная запись про уровень 55 маркер не сдвинет — проверено тестом.

**Ни один href не содержит `scenario`** — проверяется и unit-, и e2e-тестом по всем ссылкам страницы.

### SSR / hydration

Сервер `sessionStorage` не читает и рендерит ответ **последовательности** — безопасный дефолт, который
он единственно и может знать честно. Клиент дорезолвливает через `useSyncExternalStore`
(server snapshot = пустой прогресс), поэтому нет ни mismatch, ни кадра неверного ответа.

Снимок — **сериализованная строка**, а не разобранный объект: `useSyncExternalStore` сравнивает снимки
по идентичности, а `store.read()` строит новый объект на каждый вызов — возврат объекта дал бы
бесконечный ре-рендер.

## 8. Честные состояния

- **Нет открытого урока** (следующий шаг — контрольная точка, или всё пройдено): вместо мёртвого CTA —
  объяснение. Денежное условие **не превращается в призыв**.
- **Модуль без доступных действий** (например, 18-й): «Уровни этого модуля пока закрыты
  последовательностью…» вместо неработающих ссылок.
- **Невалидный `?module`**: тихий безопасный откат к текущему модулю.
- **Битый session marker**: деградация в сторону locked.

**Не выдумано:** network error, server sync, backend loading, AI-рекомендации. Их не существует.
**Curriculum «resolving» тоже не выдуман:** curriculum — синхронный типизированный fixture, он ничего
не резолвит; единственная асинхронность на странице — сессия, и она решена через `useSyncExternalStore`
без экрана загрузки (показывать спиннер вместо честного ответа последовательности было бы враньём и
лишним кадром).

## 9. Финансовая приватность

Контрольная точка несёт **только** target («Баланс Pocket от $200») и то, что открывает (инструмент,
ранг, канал). Нет: баланса, «осталось $X», процента выполнения, истории депозитов, Pocket-CTA и ссылки,
XP. Закреплено тремя тестами: на сериализованной модели, на видимом тексте страницы и на всех href.

Checkpoint — **граница модуля**: холодная структурная линия + ромб-ординал, не карточка и не баннер; не
кликабелен.

## 10. Accessibility

Один `h1` («Уроки»), иерархия h1 → h2 без пропусков. `aria-current="page"` на «Уроки» в обеих
навигациях; `aria-current` на выбранном модуле и на текущем уроке. Статус уровня — **всегда слово**
(«Завершён», «Текущий урок», «Откроется после уровня 18», «Граница модуля»), никогда только цвет; для
screen reader'ов состояние дублируется в `sr-only`. Ссылки и кнопки различаются семантически: закрытый
уровень — текст, а не disabled-контрол. `:focus-visible` — из globals.

Sheet: `role="dialog"` + `aria-modal`, Escape закрывает, фокус уходит внутрь и **возвращается на
триггер**, скролл фона блокируется с восстановлением прежнего значения, список монтируется только
открытым. **Без новой зависимости.**

Desktop-индекс ниже 900px — `display: none`, что убирает его и из tab-порядка, и из дерева
доступности: дублирующихся focusable-контролов на одном вьюпорте не возникает.

200% zoom (720×450) — компактная раскладка, все функции на месте, overflow 0. Reduced motion учтён.
