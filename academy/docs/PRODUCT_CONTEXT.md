# PRODUCT_CONTEXT

Единый контекст продукта Alfa Trade Academy Web V2. Отвечает на вопросы: что это, для кого, зачем, какие принципы и границы.

## 1. Продукт

**Alfa Trade Academy (ATA)** — последовательная образовательная платформа по трейдингу. Пользователь идёт по фиксированному пути из 100 уровней (20 модулей) и:

- проходит фиксированный путь из 100 уровней;
- смотрит уроки Alex Curie;
- проходит тесты;
- выполняет сценарные и практические задания;
- заполняет reports;
- получает mentor review;
- получает XP;
- проходит финансовые контрольные точки (checkpoints);
- открывает новые инструменты;
- открывает community-каналы;
- вручную строит собственную торговую систему;
- возвращается к ранее открытым урокам и инструментам.

### Разделение ролей Pocket и ATA

- **Pocket** — торговая платформа (брокер). Здесь пользователь торгует и видит свои деньги.
- **Alfa Trade Academy** — система обучения, progression, planning, analysis, discipline и сопровождения.

ATA **не** торговый терминал и **не** имитирует его. ATA не показывает live-графики для торговли, не транслирует котировки, не открывает сделки.

## 2. Цель дизайна

Создать высококачественный, премиальный и удобный продукт, в котором комфортно проводить продолжительное время.

Пользователь за несколько секунд понимает:
1. Где он находится.
2. Какой у него уровень.
3. Какой у него rank.
4. Что уже завершено.
5. Что нужно сделать сейчас.
6. Почему следующий этап закрыт.
7. Что откроется после выполнения.
8. Как вернуться к текущему шагу.
9. Где найти ранее открытые материалы.
10. Как получить помощь.

**Главное UX-правило:** в каждый момент существует один очевидный следующий шаг.

### Чем продукт быть не должен

- generic LMS;
- admin dashboard;
- копия Pocket;
- casino-интерфейс;
- набор декоративных карточек;
- перегруженный торговый терминал.

## 3. Аудитория

- Возраст **24–45**.
- ~**30%** — полные новички.
- Остальные часто уже пробовали торговать на Pocket, но без системных знаний.
- Первое целевое гео — **Польша**.
- Интерфейс сначала на **русском**, позднее — польская локализация. RTL не требуется.
- Desktop / mobile примерно одинаково важны; один человек может использовать desktop, mobile и tablet.
- Pocket чаще открывают с телефона.
- Продукт должен быть понятен без отдельного обучения интерфейсу.
- Компоненты сразу выдерживают более длинные польские строки.

## 4. Полный redesign

Существующий пользовательский продукт **не** является визуальной основой. ATA Web V2 полностью перерисовывается с нуля.

Сохраняется только: продуктовая логика, curriculum, progression, XP, checkpoints, reports, mentor, community, tools, необходимые backend-контракты (в будущем). Старую структуру страниц нельзя автоматически копировать.

## 5. Связь с прелендингом

Прелендинг ATA уже существует и будет дорабатываться. Новый продукт воспринимается как продолжение того же бренда:

- dark-only;
- глубокие тёмные поверхности;
- холодные акценты;
- premium lighting;
- controlled glow;
- графические мотивы пути, графика и данных;
- визуальная глубина;
- Alex Curie как лицо продукта.

Точные HEX пока неизвестны — палитра не выдумывается, используются provisional semantic tokens (см. `DESIGN_SYSTEM.md`), которые позднее заменяются значениями прелендинга.

## 6. Два визуальных режима

- **Emotional / premium mode** — Главная, Путь, rank-up, checkpoint/module/tool/community completion, referral reward, level 100. Controlled glow, depth, animated path, subtle particles, объёмные rank emblems, короткие cinematic transitions.
- **Functional mode** — уроки, тесты, reports, tools, community, news, support, mentor, profile, settings. Приоритет: читаемость, скорость, понятность, стабильность, спокойные поверхности, минимум фонового движения.

Scroll-driven сцены прелендинга не переносятся во все страницы продукта.

## 7. Финансовая приватность (критичный принцип)

ATA **не показывает** пользователю: текущий balance, deposits, withdrawals, net deposits, историю broker transactions, «сколько долларов осталось», общий financial dashboard, постоянную кнопку перехода в Pocket.

Пользователь видит свои деньги **только внутри Pocket**.

ATA показывает **только точную цель** ближайшего checkpoint: «Для открытия следующего модуля требуется баланс Pocket от $300». Рядом с целью не показывается собственный баланс пользователя. Не рассчитывается «осталось $X». Checkpoint CTA не открывает Pocket.

## 8. Границы D0

D0 — только документация и единый источник истины. Не создавать приложение, зависимости, backend, CRM, Pocket-интеграцию, production API, deploy. Детали ограничений — в `../CLAUDE.md`.
