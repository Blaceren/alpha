# CONTENT_AND_TONE

Тон голоса, правила копирайтинга и канонические строки Alfa Trade Academy. Русский — первичный язык; строки проектируются с запасом под польскую локализацию.

---

## 1. Голос Alex Curie

Alex Curie — лицо продукта и голос обучающих текстов.

**Tone:**
- на «ты»;
- взрослый;
- спокойный;
- конкретный;
- мотивирующий;
- без обещаний прибыли;
- с признанием риска;
- допускаются личные истории и ошибки.

**Где появляется Alex:** lesson previews, первое знакомство, contextual tips, checkpoint explanation, возврат после паузы, открытие модуля, weekly recap, risk-состояния, editorial.

**Где НЕ появляется:** floating assistant на каждой странице, лицо на каждой карточке, маскот, навязчивые popups.

---

## 2. Общие правила копирайтинга

- Один экран — одна главная мысль и один primary CTA.
- Никаких обещаний прибыли, гарантий дохода, «легко заработать».
- Признание риска там, где речь о торговле.
- Спокойные формулировки в проблемных состояниях (fail, rejected, grace, suspended) — без вины и давления.
- Никакого deposit-pressure и casino-ургентности («успей», «только сейчас», «последний шанс»).
- Числа/суммы — только целевые пороги checkpoint; никогда не собственный баланс пользователя.
- Не использовать «осталось $X».
- Термины Pocket/ATA разделяются: Pocket — где торгуют и видят деньги; ATA — где учатся и ведут систему.

## 3. Канонические строки (RU)

Эти формулировки зафиксированы; менять только осознанно.

### Финансовая приватность / checkpoint
- Цель: **«Для открытия следующего модуля требуется баланс Pocket от $300».** (сумма — по уровню)
- Current-объяснение: **«Учитывается только реальный баланс. Demo не засчитывается».**
- Checking: **«Проверяем выполнение условия. Обычно это занимает немного времени».**
- Data unavailable: **«Данные обновляются. Подожди немного — проверка продолжится автоматически».**
- Grace: **«Условие контрольной точки временно не подтверждено. Всё, что ты уже открыл, остаётся доступно. Статус обновится автоматически».**
- Completed CTA: **«Продолжить путь».**
- Current CTA: **«Проверить выполнение».**

### Отчёты
- Pending: **«Обычно проверка занимает до одного дня».**
- (Без countdown и без имени/аватара конкретного ментора.)

### Регистрация Pocket (L1) — канонические строки
Пользователь **не подключает и не связывает** аккаунт. Это регистрация. Запрещены: «Подключить Pocket», «Связать Pocket», «Connect Pocket», «Pocket connection» (как пользовательское действие).
- Задание: **«Регистрация Pocket»**.
- CTA: **«Перейти к заданию регистрации»**.
- Действие: **«Подтвердить регистрацию»**.
- Проверка: **«Регистрация проверяется»**.
- Успех: **«Регистрация подтверждена»**.
- Ошибка: **«Не удалось подтвердить регистрацию»**.
- Ветка для существующего аккаунта: **«У меня уже есть аккаунт»** — отдельный instruction flow (ordered steps → warning → confirmation → возврат к проверке). Точный текст инструкции утверждается позднее. После завершения registration flow нет прямой кнопки перехода из продукта в Pocket.

### Серия обучения
- После пропуска: **«Продолжим с текущего этапа».**
- Публичное название серии: **«Серия обучения».**

### Locked level (explainer)
Структура: что это → почему закрыто → что нужно сделать → что откроется. Без обещания «перепрыгнуть».

### Возврат после паузы
- Тёплое, без вины: приветствие от Alex + один следующий шаг. Без «ты давно не заходил» в укоряющем тоне.

## 5. Тон по состояниям

| Состояние | Тон | Пример-направление |
|-----------|-----|--------------------|
| failed test | поддерживающий, объясняющий | показать правильный ответ + почему, предложить повтор |
| rejected report | конструктивный | комментарии к секциям, «доработай и отправь снова» |
| grace | спокойный, без тревоги | доступ сохранён, статус обновится |
| suspended | без давления | что сохранено; никакого «пополни срочно» |
| rank-up | сдержанно-праздничный | достижение + practical unlock, без casino |
| milestone (L100) | значимый, не финальный | «переход к собственной системе», не «конец» |
| pause mode | без стыда | «пауза — инструмент контроля, а не поражение» |

## 6. Локализация (PL-готовность)

- Строки закладываются с запасом длины (+30–40%); компоненты не ломаются.
- Не конкатенировать предложения из фрагментов — использовать целостные ключи с плейсхолдерами (`{amount}`, `{level}`).
- Множественные числа через ICU/plural-правила (важно для PL).
- Даты/время/timezone — локализуемые форматы (актуально для News Calendar).
- RTL не требуется.
- Валютные пороги ($) остаются в долларах как условие Pocket; переводится обрамляющий текст, не сумма.

## 7. Запрещённая лексика

- «гарантированная прибыль», «доход без риска», «легко/быстро заработать»;
- casino-ургентность: «успей», «горит», «последний шанс», «только сегодня»;
- deposit-pressure: «пополни, чтобы не потерять доступ», «осталось $X до цели»;
- обвиняющие формулировки в fail/pause/suspended.
