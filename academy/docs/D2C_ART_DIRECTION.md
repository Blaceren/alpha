Три **структурно разных** направления страницы `/lessons`. Проходят `ata-art-direction-gate`
(19-пунктовый бриф на направление), опираются на `ata-brand-language` и
`design-memory/references/ata-brand/REFERENCE_MANIFEST.md`.

Baseline: `eea3c1f`. Scope и канонический сценарий: `docs/D2C_LESSONS_LIBRARY_SCOPE.md`.

> **РЕШЕНО (D2C-B).** Пользователь выбрал **Concept B «Curriculum Index»**. Из **Concept A** перенесён
> ровно один элемент и только для mobile — компактный переключатель модуля + доступ к полному списку
> (постоянная левая рейка A **не** перенесена). **Concept C отклонён**: он дублировал бы Главную
> (текущий урок + CTA + будущая контрольная точка) и размывал границу с Путём. Реализация —
> `docs/D2C_LESSONS_LIBRARY.md`, решения DD-261…DD-263.

> Документ ниже сохранён как **зафиксированное состояние выбора**: три брифа и их риски остаются
> контекстом принятого решения и не переписываются задним числом.

## Общее для всех трёх

Одинаковы (чтобы сравнивался **только** art direction): реальный shell (`home.css`), реальные токены
(`tokens.css`), реальные шрифты (@fontsource), канонические подписи навигации, один сценарий (Артём ·
модуль 04 · уровень 18 · 2 из 5 · checkpoint $200), вся curriculum-копия из fixtures.

**Landing-only, что во всех трёх сознательно НЕ перенесено** (манифест §C): постоянный blur/bloom по
большим зонам; giant empty hero; низкоконтрастный body; декоративные ценовые метки и рыночные
графики; tiny tracked labels для важной информации; scroll-driven cinematic сцены; perspective grid;
текст поверх активного светящегося фона. Плюс общий запрет фазы: **ни одной lock-иконки** —
закрытость передаётся тишиной (приглушённый текст, отсутствие действия), а не стеной замков.

# Direction A — «Module Desk»

1. **Product thesis.** ATA — последовательная образовательная система, где в каждый момент есть один
   очевидный следующий шаг; «Уроки» — рабочее место, за которым этот шаг делается.
2. **Concrete user moment.** Артём открывает «Уроки» в середине модуля 04: уровни 16–17 позади,
   уровень 18 не досмотрен, впереди practical 19 и контрольная точка 20. Он пришёл продолжить.
3. **Visual thesis.** Модуль открыт как **лист на рабочем столе**: узкая рейка программы слева, одна
   доминирующая рабочая поверхность справа. Текущий урок — не «карточка покрупнее»: **строка списка
   сама разворачивается в рабочую плоскость**.
4. **Stable visual DNA** (манифест §A): (1) deep navy spatial field; (4) **one dominant meaningful
   object** — плоскость ровно одна на экран; (6) fine contextual metadata (kind · длительность ·
   субтитры как аннотации, а не декор).
5. **Provisional idea (ровно одна)** (§B): **Signal point / current-position marker** — светящаяся
   точка-узел текущей позиции (реф. 03). Здесь она проверяется в роли **маркера строки списка**.
6. **Signature object.** **The Desk Sheet** — рабочая плоскость, вырастающая вбок из строки текущего
   уровня. Функция: несёт цель урока, метаданные и единственный CTA; её присутствие = «вот твоё
   рабочее место», её единственность = «работа одна».
7. **Spatial composition.** Две области: рейка 248px (все 20 модулей, подписанные) + рабочая
   поверхность. Внутри поверхности — один вертикальный ритм строк-уровней с hairline-разделителями;
   плоскость разрывает ритм ровно в одном месте. Не сетка карточек.
8. **Typography strategy.** Display (Manrope 700) — имя модуля (h1) и заголовок текущего урока; UI
   (Inter) — тела строк 15px/600 и метаданные 12.5px; mono (JetBrains) — только ordinals и время.
   Три уровня текста (primary/secondary/muted), контраст поднят относительно лендинга.
9. **Materials strategy.** Поверхности: (1) поле страницы; (2) рейка, отделённая одной hairline;
   (3) плоскость — левое signal-правило 2px + горизонтальный градиент surface-context, **без рамки по
   периметру**; (4) выделение текущего модуля в рейке — краевое правило + 8% tint. Ни одной
   карточки с полной обводкой; glow — только вокруг узла текущего уровня.
10. **Navigation strategy.** Канонический shell без изменений; «Уроки» — active. Рейка = переключение
    модуля в один клик, состояние — `aria-current`. Уровни: доступные — ссылки, закрытые — текст.
11. **Progression strategy.** Прогресс — через **геометрию маркеров** (пройден = залитая точка;
    текущий = кольцо с glow; следующий = полая точка; checkpoint = ромб), тот же словарь, что у
    `.modline` Главной. Плюс «2 из 5» словами. Никаких progress rings и XP.
12. **Alex Curie strategy.** Отсутствует — сознательно. «Уроки» — обзор материала; ментор появляется
    в уроке и в mentor-фазах. Клеить аватар на библиотеку = декор без функции.
13. **Motion strategy.** Functional-режим: hover/focus 140 ms, разворот плоскости при смене модуля
    ≤200 ms. Никаких milestone-сцен: `/lessons` — functional-страница.
14. **Mobile transformation.** Рейка **не превращается в скролл-колонку**: она сворачивается в
    **однострочный степпер модуля** (‹ «Модуль 04 · из 20» ›, цели ≥44px), а стол становится единым
    потоком. Завершённые уровни сжимаются в одну строку («Завершён · Пересмотреть»), чтобы CTA
    текущего урока оставался в первом экране над bottom nav.

16. **How it differs from D1A.** Отклонённый D1A (`design-memory/references/anti-examples/d1a-generic/`)
    — сетка одинаковых карточек с KPI-плитками и одинаковым radius. Здесь карточек нет вообще: одна
    плоскость и один список; выделение — краевыми правилами и геометрией маркеров, не контейнерами.
17. **Why it can't be renamed to another SaaS.** Рейка+область — узнаваемая связка (это и есть риск),
    но переименовать нельзя из-за **разворачивающейся строки**: рабочая поверхность не существует
    сама по себе, она принадлежит **ровно тому уровню, на котором стоит пользователь**, и исчезает
    вместе с ним. В админке рабочая область — контейнер для чего угодно; здесь она — состояние
    прогрессии.
18. **Reference screenshots.** `prelanding-desktop-03` (точка-сигнал текущей позиции; фасетчатые
    холодные материалы) и `prelanding-desktop-04` (нумерованная последовательность 01→N как реальный
    порядок; более контрастные заголовки; line-иконки только как вторичная метаданность).
19. **Landing-only NOT transferred.** Сверх общего списка: **giant A** как объект здесь не
    используется вовсе; свечение не размазано по фону — оно только у узла текущего уровня.

# Direction B — «Curriculum Index»

1. **Product thesis.** Тот же продукт; «Уроки» — **содержание** учебной системы, к которому
   возвращаются.
2. **Concrete user moment.** Тот же (Артём, модуль 04, уровень 18). Дополнительно: он хочет одним
   взглядом понять масштаб программы и найти пройденный материал.
3. **Visual thesis.** Curriculum читается как **содержание книги**: моноширинные ординалы, отточия,
   состояния по правому краю. Текущий урок выделен **типографикой и ритмом**, а не размером
   контейнера. Ни одной карточки на странице.
4. **Stable visual DNA** (§A): (1) deep navy field; (6) **fine contextual metadata** — состояние как
   отдельный смысловой столбец; (7) restrained cinematic depth — глубина здесь почти целиком
   типографическая.
5. **Provisional idea (ровно одна)** (§B): **Gradient/tracked eyebrow + осмысленная нумерация
   последовательности 01→N** (реф. 04) — проверяется, держит ли нумерация всю иерархию 20/100 **без**
   графической опоры.
6. **Signature object.** **The Index Line** — строка содержания: `ординал · название · отточие ·
   состояние`. Функция: одна строка = один модуль/уровень + его состояние; страница целиком
   построена из одного этого объекта в двух масштабах (модули и уровни).
7. **Spatial composition.** Полоса «Продолжить» во всю ширину (две hairline + левое signal-правило,
   **не карточка**), под ней два уровня индекса: содержание 20 модулей (левая колонка, узкая, тихая)
   и раскрытый модуль (правая, крупнее). Все 20 модулей закрываются **выше сгиба** на 1440×900.
8. **Typography strategy.** Типографика **несёт всю иерархию**: mono-ординалы 11.5–12.5px; названия
   модулей 13px secondary; уровни 14.5px/600 primary; текущий урок 16px/700 — единственная
   утяжелённая строка. Отточие — 1px dotted. Никакого uppercase для важного.
9. **Materials strategy.** Материалов почти нет — и это позиция: поле + hairlines + одно
   signal-правило + один 9% tint на строке текущего урока. Глубина из ритма и веса, а не из слоёв.
10. **Navigation strategy.** Shell без изменений. Навигация = сам индекс: клик по модулю раскрывает
    правый столбец; `aria-current` на текущем модуле и текущем уроке.
11. **Progression strategy.** Состояние — **слово в правом столбце** («пройден», «2/5», «далее»,
    «впереди») + одна signal-точка у текущего модуля. Самый «текстовый» способ: масштабируется до 100
    уровней без единого нового графического примитива.
12. **Alex Curie strategy.** Отсутствует — как в A, и по той же причине.
13. **Motion strategy.** Минимальная: hover-подсветка строки 140 ms, раскрытие модуля ≤200 ms.
    Индекс — самый спокойный экран продукта.
14. **Mobile transformation.** Порядок инвертируется: **раскрытый модуль первым**, полное содержание
    программы — вторым уровнем ниже (DOM-порядок = порядок чтения = порядок экрана, без
    `order`-рассинхрона). Отточия **выключаются** — на 390px они вырождаются в 20px-огрызки; их роль
    берёт правое выравнивание столбца состояний.

16. **How it differs from D1A.** D1A был стеной контейнеров; здесь контейнеров **ноль**. Плотность
    достигается ритмом строк, а не плитками; ни одного radius-повтора, потому что ни одной коробки.
17. **Why it can't be renamed to another SaaS.** Индекс держится на **осмысленной сквозной нумерации

    последовательной программе с контрольными точками. Убрать номера и состояния — рассыпается сам
    объект; это не таблица данных, которую можно наполнить чем угодно.
18. **Reference screenshots.** `prelanding-desktop-04` (нумерованная последовательность как
    структура; более высокий контраст заголовков; правые фичи-строки = metadata с функцией) и
    `prelanding-desktop-02` (тонкие координатные подписи-узлы вокруг объекта → здесь: столбец
    состояний как аннотация к каждой строке).
19. **Landing-only NOT transferred.** Сверх общего: отказ от **свечения как средства иерархии** —
    в B светится ровно одна точка; и отказ от tracked-uppercase подписей (в лендинге ими подписано
    важное — здесь важное набрано весом).

# Direction C — «Learning Brief»

1. **Product thesis.** Тот же продукт; «Уроки» объясняют **смысл** текущего обучения, а не только его
   состав.
2. **Concrete user moment.** Тот же. Дополнительно: Артём не помнит, **зачем** ему уровень 18 и что
   он этим откроет.
3. **Visual thesis.** Страница — **аргумент, а не каталог**. Сверху бриф текущего обучения; ниже —
   структура с progressive disclosure. Текущий урок и следующий practical связаны **одной учебной
   логикой**, а не соседством в списке.
4. **Stable visual DNA** (§A): (5) **chaos → system narrative** — направленный переход, здесь в виде
   учебной причинности; (4) one dominant meaningful object; (2) luminous line used as structure.
5. **Provisional idea (ровно одна)** (§B): **Вертикальный световой луч → Learning Spine** (реф. 04) —
   проверяется **вне** страницы Пути и **вне** урока: как цепочка ролей, которая на mobile
   выпрямляется в вертикальную ось, а на desktop ложится горизонтально.
6. **Signature object.** **The Brief Chain** — цепь из трёх звеньев с **ролями**: «Изучаю сейчас» →
   «Затем применю» → «И это откроет». Функция: превращает закрытые будущие шаги (practical 19,
   checkpoint 20) из «запертого будущего» в **обоснование текущего урока**. Акцент **затухает** вдоль
   цепи, поэтому закрытое не конкурирует с текущим.
7. **Spatial composition.** Бриф во всю ширину: eyebrow → имя модуля (крупно) → описание → цепь из 3
   звеньев (desktop горизонтально, соотношение 1.55 : 1 : 1) → строка «уже изучено». Ниже, за
   разделителем — «Программа»: 20 модулей в **две текстовые колонки** (не сетка карточек).
8. **Typography strategy.** Display 700 — имя модуля 38px (самый крупный текст продукта на этой
   странице) и заголовки звеньев; роли звеньев 12px/600 (единственный цвет-код: green/blue/muted);
   тела 14px; mono — ординалы и время. Затухание кегля вдоль цепи: 24 → 16 → 16.
9. **Materials strategy.** Ровно **одна** поверхность на странице — под звеном «Изучаю сейчас»
   (холодный слой + hairline, скруглена только со стороны, противоположной цепи). Остальные звенья
   материала не имеют: они — текст на поле. Соединительная ткань цепи — 1.5px правила с
   состояние-зависимым цветом.
10. **Navigation strategy.** Shell без изменений. Переключение модулей — из списка «Программа»
    (второй уровень); бриф всегда о текущем/выбранном модуле.
11. **Progression strategy.** Прогресс выражен **причинностью**, а не шкалой: три роли + «уже изучено
    в модуле · 2 из 5» + маркеры-геометрия (кольцо с glow / полая точка / ромб). Никаких колец и XP.
12. **Alex Curie strategy.** Отсутствует. Бриф — голос **системы**, не человека; подмешивать сюда
    ментора значит спорить с уроком, где он уже есть.
13. **Motion strategy.** Functional. Единственное осмысленное движение — перестроение цепи при смене
    breakpoint (не анимируется) и hover/focus 140 ms. Milestone-сцены — не здесь.
14. **Mobile transformation.** Цепь **поворачивается**: горизонтальный аргумент становится
    **вертикальной осью** (это и есть проверка Learning Spine) с теми же ролями; соединительные
    правила становятся спайном. Список программы из двух колонок сворачивается в одну. Бриф остаётся
    первым экраном, CTA — над bottom nav.

## Сравнение направлений

| | **A — Module Desk** | **B — Curriculum Index** | **C — Learning Brief** |
|---|---|---|---|
| Пространственная система | рейка + рабочая поверхность | двухуровневый типографический индекс | бриф-аргумент + второй уровень |
| Signature object | Desk Sheet (разворачивающаяся строка) | Index Line (ординал·название·отточие·состояние) | Brief Chain (3 роли) |
| Чем выделен текущий урок | **материалом** (единственная плоскость) | **типографикой и ритмом** | **ролью в аргументе** |
| Как отвечает на «что изучаю» | показывает рабочее место | показывает положение в содержании | **объясняет причину** |
| Обзор всех 20 на 1-м экране | да (рейка, с подписями) | **да (весь индекс, выше сгиба)** | частично (ниже брифа) |
| Масштабируемость 20/100 | хорошая (рейка фиксирована) | **лучшая (~28px строка)** | средняя (бриф занимает верх) |
| Плотность | средняя | высокая | низкая сверху / высокая снизу |
| Mobile-приём | степпер модуля | инверсия уровней, отточия выкл. | цепь → вертикальная ось |
| Provisional идея (§B) | signal point | нумерация 01→N | Learning Spine |
| Ближайшая опасность | admin/IDE-панель | документация/спецификация | вторая Главная |
| Отличие от Path | список ≠ маршрут; нет траектории и viewport-рамки | индекс ≠ карта; состояние словом, а не положением | причинность ≠ последовательность |

### Сильные стороны и риски (сжато)

- **A.** + Профессиональное учебное рабочее место; один объект в фокусе; все 20 модулей подписаны;
  переключение — один клик. − Рейка+область — самая узнаваемая связка admin/IDE; рейка отнимает
  ~250px у содержания; на планшете конкуренция за ширину обострится.
- **B.** + Самый масштабируемый под 20/100; плотность без веса; ни одной карточки и lock-иконки;
  весь curriculum виден сразу. − Самый «сухой»: близок к спецификации; слабее всех отвечает на
  «зачем»; премиальность целиком на дисциплине типографики — при малейшем послаблении станет
  таблицей.
- **C.** + Единственный объясняет учебную логику; закрытые шаги работают на текущий, а не против
  него; затухание акцента встроено в композицию; лучший mobile-приём. − Ближе всех к Главной (текущий
  урок + CTA + будущий checkpoint) — риск «второй Главной»; обзор программы уезжает ниже сгиба.

## Статус

- Три направления **структурно различны** (разные пространственные системы, разные signature objects,
  разные способы выделить текущий урок — не перестановка блоков одного скелета).
- **Выбран Concept B** + mobile-переключатель из A; C отклонён (DD-261).
- Реализация выполнена в D2C-B: `docs/D2C_LESSONS_LIBRARY.md`,
  review — `design-memory/reviews/d2c-b-lessons-library-review.md`.
- Риск B, зафиксированный здесь заранее («самый сухой, близок к документации»), отработан в реализации:
  усилен заголовочный кегль, полоса продолжения получила материал и CTA рядом с текстом, у текущего
  уровня появилась рабочая иерархия, отточия убраны из строк уровней, secondary metadata поднята с
  `--text-muted` до `--text-secondary` (D2C-B review §2).
