# D1A-R2 — Mobile behavior (390×844)

Mobile — самостоятельная композиция, **не** уменьшенный desktop. Одна система, два состояния.
Bottom navigation: Главная · Путь · Уроки · Инструменты · Ещё. Профиль — через avatar. Touch ≥44px.

## State A — Active lesson
- **Current node в центральной зоне** экрана — пространственный якорь со светом.
- **Adjacent levels частично видны**: «‹ 17» слева, «19 · ◇20 ›» справа.
- **Route уходит диагонально за экран** (снизу-слева вверх-направо) — визуальный сигнал, что маршрут можно двигать (свайп).
- **Current lesson раскрывается рядом с node** (plane сразу под узлом): урок + mini-spine модуля + CTA.
- **CTA «Продолжить урок» полностью виден**, во всю ширину, ≥48px.
- **rank/XP/streak — одна строка** с точками-разделителями (не три карточки).
- **Checkpoint preview вторичен** — компактный tag внизу.
- **Alex компактно** — портрет-frame 44px + короткая цитата.
- Подсказка «↔ маршрут можно двигать · ⟲ к текущему уровню».

## State B — Current checkpoint
- **Checkpoint gate — центральный объект** вверху: вертикальная ось + glow-focus, маршрут упирается в ворота.
- **Условие читается без длинного scroll**: «Баланс Pocket от $200» + «учитывается только реальный баланс, demo не засчитывается».
- **CTA «Проверить выполнение» в первом viewport**, во всю ширину.
- **Награда + rank preview видны** одним объектом («За воротами · Наблюдатель IV · Chart Markup Tool»).
- **Прошлый маршрут частично виден** снизу-слева («Пройдено 16–20 ↙»).
- **Bottom navigation не перекрывает контент** (контент в пределах ~760px, nav 60px + safe-area).
- Без баланса пользователя, без «осталось $X», без Pocket-CTA.

## Общие правила
- Никаких rank/XP/streak как трёх карточек; никаких card-grid; никакого stacked-desktop.
- Один glow-focus (node в A / gate в B). Один primary CTA на экран.
- Горизонтальный/диагональный route-overflow — внутри своего слоя, страница по горизонтали не скроллится.
