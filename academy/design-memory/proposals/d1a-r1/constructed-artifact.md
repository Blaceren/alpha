# Art Direction Sheet — Direction C: Constructed Artifact

Low-fidelity structural proposal (D1A-R1). Design-only, no React. Terminology RU user-facing.
Product name: **Alfa Trade Academy**. Shared product content — see `_shared-state.md`.

1. **Product thesis.** По мере продвижения пользователь **собирает** единый объект — свою систему;
   каждое действие добавляет ему структуру.
2. **User moment.** Артём, уровень 18, модуль 4, активный урок «Поддержка и сопротивление». Открывает
   Главную и видит свой собираемый артефакт.
3. **Visual thesis.** Прогресс = **один центральный конструируемый артефакт**; маршрут входит в объект и
   выходит из него; экран организован вокруг объекта, а не вокруг карточек.
4. **Stable DNA principles.** Constructed object made from lines/data/layers; one dominant meaningful
   object; luminous line used as structure (route в/из объекта); chaos→system narrative; deep navy field;
   fine contextual metadata; restrained cinematic depth.
5. **Provisional ideas tested.** Ровно одна: **Constructed Market Artifact** (кандидат из manifest §B,
   кадры 02–03 — объект из линий/данных/слоёв).
6. **Signature object.** Центральный **Constructed Market Artifact** — объект, собираемый из фрагментов.
7. **Functional meaning of signature.** Кодирует: rank (общая форма/тир), module (текущая фаза сборки),
   progress (степень собранности 2/5), current lesson (активный фрагмент), next unlock (пустой слот
   награды). Не логотип.
8. **Desktop composition.** Один артефакт в центре; **route входит слева и выходит справа** (хаос→
   структура); активный фрагмент подсвечен; вокруг — подключённые capabilities (инструменты как элементы
   объекта), а не карточки. Нет sidebar, нет сетки карточек.
9. **Navigation model.** **Top-oriented / radial** — верхняя полоса + радиальные контролы вокруг объекта.
   НЕ левый sidebar.
10. **Progression model.** Радиальная/сборочная геометрия: прогресс = степень сборки объекта; будущее =
    не пристыкованные фрагменты/фазы; контрольная точка = следующая конструктивная фаза.
11. **Current lesson placement.** **Активный фрагмент/слой** объекта: «Поддержка и сопротивление · Модуль
    4 · 2/5», к фрагменту прикреплено «Продолжить урок».
12. **Checkpoint placement.** **Следующая конструктивная фаза** (ghost-контур сверху объекта):
    «Контрольная точка · Уровень 20 · от $200» — открывает следующий слой сборки. Без баланса, без Pocket-CTA.
13. **Reward placement.** **Новый функциональный элемент** объекта — Chart Markup Tool показан как ещё не
    пристыкованный фрагмент у фазы L20.
14. **Rank placement.** Выражен **формой/тиром всего артефакта** («Наблюдатель III»), а не отдельным гексагоном.
15. **Alex Curie placement.** Выноска, **объясняющая текущий фрагмент** (у активного слоя объекта).
16. **Typography hierarchy.** H1 — активный фрагмент/урок; secondary — метки capabilities и фаз; mono —
    XP/степень сборки/уровень. Высокий контраст.
17. **Surface strategy.** Поверхности как **слои объекта**: собранные фрагменты (плотные), активный
    (подсвеченный), не собранные (ghost). Плюс navy поле и линия-route. Не «стена карточек», не единый radius.
18. **Motion concept.** Functional: подсветка активного фрагмента; лёгкое «примыкание» при завершении шага.
    Milestone (открытие фазы/награды) — вне первого экрана. Reduced-motion → статичный объект.
19. **Mobile transformation (390×844).** Артефакт **упрощается до focused object** в центре; детали
    появляются по **тапу**; route превращается в **компактную ось вокруг объекта**; CTA «Продолжить урок»
    сохраняет визуальный приоритет; **никакого вертикального списка карточек**; bottom nav доступна.
20. **Что намеренно не взято из прелендинга.** Низкий контраст; giant empty hero; tiny tracked labels;
    декоративные цены; постоянный blur; giant A как логотип; ghost-CTA-форма; grid perspective (§C/§B).
    Объект — функциональный конструкт, не декоративная буква A.
21. **Почему нельзя переименовать в другой SaaS.** Экран = **сборка личной торговой системы**: фрагменты
    = уроки, фазы = контрольные точки, элементы = инструменты, форма = ранг. Это ATA-модель построения
    системы, а не универсальный объектный просмотрщик.
22. **Отличие от rejected D1A.** D1A: карточки инструментов/наград + гексагон-ранг + path-виджет. Здесь:
    инструменты = части объекта, ранг = форма объекта, прогресс = степень сборки; ни одной карточки-контейнера.
23. **UX risks.** Метафора сборки может быть неочевидна → явные метки фрагментов и «Продолжить урок» в
    приоритете; радиальная навигация → дублировать критичные действия в top-полосе для доступности.
24. **Performance risks.** Слоистый объект → следить за перерисовкой; свечение активного фрагмента — бюджет кадра.
