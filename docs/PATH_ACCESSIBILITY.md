# PATH_ACCESSIBILITY — доступность страницы «Путь»

## Двухслойная модель

Визуальный Route Field — **представление**; параллельно существует настоящая семантическая
структура прогрессии, видимая AT и тестируемая:

1. **Интерактивный слой.** Каждый узел — реальный `<button>` с полным именем
   («Уровень 18 — Поддержка и сопротивление, текущий»), roving tabindex (в поле один Tab-stop),
   `aria-current="step"` на текущем; лента модулей — `<nav aria-label="Модули пути">` со списком
   кнопок («Модуль 4 „Чтение графика“ — уровни 16–20, текущий», `aria-pressed` на выбранном).
2. **Текстовая альтернатива.** `PathAccessibleOutline` — sr-only
   `<nav aria-label="Структура пути — текстовая версия">`: ordered list всех 20 модулей
   (название, диапазон, состояние), внутри выбранного — ordered list его уровней с состоянием
   текстом и `aria-current="step"` на текущем; у checkpoint-уровней — условие и «что откроется».
   Существование и содержимое закреплены component-тестом.

## Выполненные требования (§18)

- Один `h1` («Путь») — component + e2e.
- Landmarks: header, две `<nav>` (модули, текстовая структура), `<aside>` detail с aria-label.
- `aria-current="step"` — на текущем узле и в outline.
- Критический текст не живёт в SVG: слой соединений — `aria-hidden` дубль; все смыслы — DOM-текст
  (labels узлов, gate-info, header, detail, outline).
- Состояние не только цветом: геометрия маркеров (диск/кольцо/пунктир/ромб) + текст
  («пройден/текущий/следующий/закрыт/контрольная точка …»).
- Focus order = учебная последовательность: ←/→ идут по уровням (через границы модулей),
  Enter/Space — detail, Escape — закрыть (фокус возвращается на узел, не теряется), Home — к текущему.
- Видимый фокус: outline-кольцо маркера (`:focus-visible`).
- 200% zoom — reflow в компакт-композицию (e2e 720×450, без горизонтального overflow).
- Reduced motion: пульс узла отключён (глобальное правило + e2e-проверка `animationName === "none"`),
  автоцентрирование — instant, смысл сохраняется.
- Touch: узлы и сегменты ленты ≥44px hit-area; sheet выше bottom nav (bounding-box e2e).

## Известное ограничение (зафиксировано)

Полное дублирование `aria-current` в двух слоях (кнопка + outline) намеренно: это две независимые
навигационные структуры. Скринридерный порядок: header → лента модулей → поле (кнопки уровней) →
detail (при открытии фокус на заголовок) → текстовая структура.
