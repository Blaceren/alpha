# D1A_R1_STRUCTURAL_COMPARISON

Проверка, что три направления (Route Field / Learning Spine / Constructed Artifact) **структурно
различны**, а не перестановки одного skeleton. Одинаковый product content (см.
`design-memory/proposals/d1a-r1/_shared-state.md`). Скриншоты — `design-memory/screenshots/d1a-r1-low-fi/`.

## Сравнение по обязательным вопросам

| Вопрос | A · Route Field | B · Learning Spine | C · Constructed Artifact |
|--------|-----------------|--------------------|--------------------------|
| **Navigation model различна?** | Compact **top command strip** + edge-control возврата | **Сама вертикальная ось = навигация** + минимальный top bar | **Top-oriented + radial** контролы вокруг объекта |
| **Progression geometry различна?** | **Горизонтальная** линия-канвас | **Вертикальная** ось | **Радиальная / сборочная** (степень собранности) |
| **Placement primary action различен?** | У **активного узла** на линии (контекст разворачивается из узла) | В **единой рабочей плоскости** справа от оси | Прикреплён к **активному фрагменту** объекта |
| **Роль signature object различна?** | Линия **является самим экраном** (canvas) | Ось **является навигацией+прогрессом** | Объект **кодирует** rank/module/progress/lesson/unlock |
| **Mobile transformation различна?** | Горизонтальный **swipe**, current node = центр | Вертикальный **segment-focus** (не timeline) | **Focused object + компактная орбита**, детали по тапу |
| **Spatial hierarchy различна?** | Поле → линия → один разворот у узла | Поле → ось → одна рабочая плоскость | Поле → слои объекта → один фрагмент-плоскость |
| **Content reveal различен?** | Разворот **из узла** линии | Раскрытие **в рабочую плоскость** из узла оси | **Тап по фрагменту** / подсветка активного слоя |
| **Можно получить перестановкой другого?** | Нет | Нет | Нет |

## Вывод

Три направления построены на **трёх разных пространственных системах** (горизонтальная линия /
вертикальная ось / радиально-собираемый объект), с разными navigation models, разной геометрией
прогресса, разным размещением primary action и разными mobile-трансформациями. Ни одно **не**
получается простым rearrange блоков другого (это не перестановка карточек, не смена фона, не только
glow/hero-size/whitespace, не общий sidebar). Требование «если два можно получить перестановкой — одно
отклонить» **не сработало**: все три структурно независимы.
