# Public Home — карточка «ATA — это не» (DD-372, 2026-10-08)

Владелец (скриншот карточки): «тут сделать сильно интереснее, анимации, акценты и текста улучшить, довести до
продакшен хай фай». Направление выбирал сам (делегировано с 02.10), выкат по готовности.

## Что было

Тёмная карточка с моно-меткой «ATA — это не» и пятью приглушёнными строками через волосяные линии
(«сигнальный сервис; копирование сделок; торговый терминал; управление капиталом; обещание прибыли.»).
Карточка растягивалась до высоты вступления слева — треть её пустовала. Ни акцента, ни движения; только
отрицание.

## Три направления

- **A. «Не — а» — выбрано.** Каждая строка говорит не только, чем ATA не является, а и чем является вместо
  этого: отрицание приглушённым за крестиком, ответ светлым за лаймовой точкой (точки маршрута DD-370). Карточка
  с уголками рамки первого экрана; при появлении строки входят одна за другой, у каждого ответа один раз
  вспыхивает точка. Текст улучшен по сути: отрицание превращается в утверждение о работе ученика.
- **B. «Вычёркивание».** Строки зачёркиваются лаймовой линией слева направо. Отклонено: приём отклонён ещё в
  DD-345 («читается как ошибка»); под меткой «это не» зачёркивание — двойное отрицание.
- **C. «Бегущий сигнал».** Лаймовая точка пробегает по линиям сверху вниз, зажигая крестики. Отклонено:
  украшение без смысла, текст остаётся отрицанием.

| копирование сделок | собственное основание каждой сделки |

Ни один ответ не обещает результата (тест держит: в ответах нет «прибыл/доход/заработ/гарант»); «прибыл» на
странице — по-прежнему один раз, в «обещание прибыли» (тест честности считает).
