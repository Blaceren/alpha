# Art Direction Sheet — Direction A: Route Field

Low-fidelity structural proposal (D1A-R1). Design-only, no React. Terminology RU user-facing
(Контрольная точка, Ранг, Отчёт, Сообщество). Product name: **Alfa Trade Academy** (never «Alpha Trade»).
Shared product content — see `_shared-state.md`.

1. **Product thesis.** Alfa Trade Academy ведёт трейдера по фиксированному маршруту из 100 уровней;
   в каждый момент — один очевидный следующий шаг.
2. **User moment.** Артём, уровень 18, модуль 4 «Чтение графика», активный урок «Поддержка и
   сопротивление», в двух уровнях от контрольной точки L20. Он открывает Главную, чтобы продолжить.
3. **Visual thesis.** Главная — это **не dashboard, а участок живого маршрута**: пользователь
   находится *внутри* progression field, а не смотрит на карточки со стороны.
4. **Stable DNA principles.** Luminous line used as structure; one dominant meaningful object;
   chaos→system narrative; deep navy spatial field; fine contextual metadata; restrained cinematic depth.
5. **Provisional ideas tested.** Ровно одна: **Luminous Route Trace** как горизонтальный canvas
   (кандидат B из manifest §B).
6. **Signature object.** Горизонтальная **Luminous Route Trace** — сама линия маршрута во всю ширину.
7. **Functional meaning of signature.** Линия кодирует: completed segment (пройденный путь), active
   point (текущий уровень), locked segment (закрытое впереди), checkpoint (структурное препятствие),
   reward (встроен в узел), и несёт control «К текущему уровню». Это persistent progression object,
   не декоративный график.
8. **Desktop composition.** Экран = один горизонтальный маршрут через всю ширину. Слева — пройденные
   узлы, по центру — крупный активный узел (L18), справа — закрытые узлы и дальше по линии
   узел-препятствие контрольной точки (L20) с встроенной наградой. Из активного узла **разворачивается**
   контекст текущего урока и primary action. Никакого sidebar, никакой сетки карточек.
9. **Navigation model.** **Compact top command strip** (тонкая верхняя полоса: wordmark слева,
   горизонтальный ряд разделов, уведомления + avatar справа). Дополнительно — edge control «К текущему
   уровню». Это НЕ левый sidebar.
10. **Progression model.** Горизонтальная геометрия: прогресс читается слева-направо по линии;
    позиция = точка на маршруте; будущее — дальше по линии; препятствие = контрольная точка.
11. **Current lesson placement.** Раскрывается **прямо из активного узла** (callout над/под точкой L18):
    «Поддержка и сопротивление · Модуль 4», прогресс 2/5.
12. **Checkpoint placement.** Дальше по линии справа как **структурное препятствие/ворота**:
    «Контрольная точка · Уровень 20 · требуется баланс Pocket от $200». Без баланса пользователя, без Pocket-CTA.
13. **Reward placement.** **Встроена в узел контрольной точки**: Chart Markup Tool как награда за прохождение L20.
14. **Rank placement.** Как **route instrumentation** — компактный прибор «Ранг · Наблюдатель III»,
    закреплённый на линии рядом с текущей позицией (не карточка, не гексагон).
15. **Alex Curie placement.** **Contextual annotation на пути** — выноска у активного узла
    («Alex: уровни — это зоны реакции рынка…»), привязанная к линии, не отдельная карточка.
16. **Typography hierarchy.** H1 — активный урок (крупно, читаемо); secondary — метки узлов/приборов;
    mono — числовые значения (уровень, XP, 2/5). Высокий контраст (не landing low-opacity).
17. **Surface strategy.** Несколько типов поверхностей, а не «стена карточек»: (a) глубокое navy поле
    (canvas), (b) сама линия-структура, (c) один разворачиваемый рабочий слой у активного узла. Тонкие
    границы, контролируемое свечение только на активной точке.
18. **Motion concept.** Functional: центрирование текущего узла; разворот контекста из узла (140–240ms);
    ambient свечения активной точки — низкой интенсивности, пауза в hidden tab, off при reduced-motion.
    Milestone (checkpoint/rank-up) — отдельно, вне первого экрана.
19. **Mobile transformation (390×844).** Canvas НЕ уменьшается. Активный узел = **центральный экран**;
    соседние уровни видны частично слева/справа (намёк на swipe); swipe двигает маршрут; действие
    «Продолжить урок» закреплено рядом с активным узлом; ранг/XP/серия и Alex — слои, раскрываемые снизу;
    bottom navigation (Главная/Путь/Уроки/Инструменты/Ещё) доступна.
20. **Что намеренно не взято из прелендинга.** Низкий контраст; giant empty hero; tiny tracked labels;
    декоративные цены; постоянный blur; giant A placement; ghost-CTA-форма; grid perspective (manifest §C/§B).
21. **Почему нельзя переименовать в другой SaaS.** Экран построен вокруг **последовательного маршрута
    обучения с контрольной точкой как препятствием и наградой-инструментом** — это ATA-progression, а не
    универсальный дашборд. Убрать маршрут — экрана не останется.
22. **Отличие от rejected D1A.** D1A: sidebar + карточки + path-виджет из плиток. Здесь: нет sidebar
    (top strip), нет карточной сетки, path — сам экран (canvas), а не виджет в карточке.
23. **UX risks.** Горизонтальный scroll может дезориентировать → нужен явный «К текущему уровню» и
    автоцентрирование; плотность приборов на линии → держать ≤ несколько readouts.
24. **Performance risks.** Длинная линия со 100 узлами → виртуализация дальних узлов; свечение — бюджет кадра.
