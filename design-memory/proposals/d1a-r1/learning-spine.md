# Art Direction Sheet — Direction B: Learning Spine

Low-fidelity structural proposal (D1A-R1). Design-only, no React. Terminology RU user-facing.
Product name: **Alfa Trade Academy**. Shared product content — see `_shared-state.md`.

1. **Product thesis.** Обучение в Alfa Trade Academy — вертикально организованная система: модуль,
   уровни, контрольная точка и открываемые возможности нанизаны на одну ось.
2. **User moment.** Артём, уровень 18, модуль 4, активный урок «Поддержка и сопротивление», близко к
   контрольной точке L20. Открывает Главную.
3. **Visual thesis.** Прогресс — это **вертикальная ось (spine)**, вдоль которой растёт система;
   экран организован осью, а не sidebar+content.
4. **Stable DNA principles.** Luminous line used as structure (вертикальная); one dominant meaningful
   object; chaos→system narrative; deep navy spatial field; fine contextual metadata; restrained cinematic depth.
5. **Provisional ideas tested.** Ровно одна: **Learning Spine** — вертикальный луч с нумерованными
   узлами (кандидат из manifest §B, кадр 04).
6. **Signature object.** Вертикальная **Learning Spine** — светящаяся ось с узлами уровней/этапов.
7. **Functional meaning of signature.** Spine показывает: module position, current level, completion
   (пройденные ниже/выше), checkpoint (усиленный узел), tool unlock (ответвления-capabilities),
   route continuity (непрерывность пути). Это navigation + progression одновременно.
8. **Desktop composition.** Вертикальная spine (левее центра) во всю высоту; узлы уровней вдоль оси;
   **одна крупная рабочая плоскость справа** с текущим уроком. Инструменты — короткие ответвления от
   spine. Нет sidebar, нет карточной сетки, нет второй колонки контейнеров.
9. **Navigation model.** **Сама spine — основная навигация** (узлы = переходы) + минимальный top bar
   (wordmark, уведомления, avatar). НЕ левый sidebar с пунктами меню.
10. **Progression model.** Вертикальная геометрия: снизу-вверх — от пройденного к будущему; текущий
    уровень — активный узел в фокусе; контрольная точка — усиленный узел выше.
11. **Current lesson placement.** На **одном уровне spine** (активный узел L18) раскрывается в правую
    рабочую плоскость: «Поддержка и сопротивление · Модуль 4 · 2/5» + «Продолжить урок».
12. **Checkpoint placement.** **Усиленный узел spine** выше текущего: «Контрольная точка · Уровень 20 ·
    от $200». Без баланса, без Pocket-CTA.
13. **Reward placement.** Ответвление у узла контрольной точки: Chart Markup Tool (награда за L20).
14. **Rank placement.** **На пересечении завершённых этапов** — маркер «Ранг · Наблюдатель III» на spine
    в точке, где завершённый сегмент встречает текущий (не карточка, не гексагон).
15. **Alex Curie placement.** Привязан к **текущему learning-узлу** — выноска у активного узла spine.
16. **Typography hierarchy.** H1 — текущий урок в рабочей плоскости; secondary — метки узлов вдоль оси;
    mono — номера уровней/значения. Высокий контраст.
17. **Surface strategy.** Три типа поверхностей: (a) navy поле, (b) светящаяся spine-структура, (c) одна
    рабочая плоскость. Тонкие границы; свечение — только активный узел. Никакой «стены карточек».
18. **Motion concept.** Functional: фокус-скролл к активному узлу; раскрытие рабочей плоскости из узла;
    ambient пульс активного узла (низкий, пауза/off при reduced-motion). Milestone — вне первого экрана.
19. **Mobile transformation (390×844).** Spine **не** превращается в длинный неудобный timeline. Текущий
    **сегмент** оси занимает основной экран (активный узел + рабочая плоскость как focused layer); соседние
    шаги видны выше/ниже частично; детали открываются focused-слоем по тапу; primary action «Продолжить
    урок» — в первом viewport; bottom nav доступна.
20. **Что намеренно не взято из прелендинга.** Низкий контраст; giant empty hero; tiny tracked labels;
    декоративные цены; постоянный blur; giant A; grid perspective; ghost-CTA-форма как правило (§C/§B).
21. **Почему нельзя переименовать в другой SaaS.** Ось прямо кодирует **учебную последовательность
    (уровни→контрольная точка→разблокировка инструмента)** с рангом на пересечении завершённых этапов —
    это структура обучения ATA, не универсальная навигация.
22. **Отличие от rejected D1A.** D1A: sidebar + main content + карточки. Здесь: навигация = сама ось,
    контент = одна рабочая плоскость; нет второго столбца карточек, нет KPI-плиток.
23. **UX risks.** Вертикальная ось на mobile может уехать в timeline → строго segment-focus, не полный
    список; правая плоскость на узком экране → focused layer, не сжатая колонка.
24. **Performance risks.** Длинная ось (100 узлов) → виртуализация; свечение узлов — бюджет кадра.
