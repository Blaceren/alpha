# WHY_REJECTED — D1A generic art directions

D1A (Product Portal / Market Atlas / Editorial Academy) технически работал, но все три
оказались вариациями **одного generic AI dashboard**. Здесь — конкретный разбор каждого кадра.
Скриншоты в этой папке — anti-examples: их нельзя воспроизводить в новых направлениях.

Сквозная проблема всех семи кадров: **один и тот же skeleton** = левый sidebar (264px, лого +
вертикальный список пунктов с Lucide-иконками) + top bar (page-context слева, bell + avatar
справа) + сетка `rounded-2xl` карточек с `border-line` на `#10141c`. Различались только
расстановка карточек, размер hero и количество glow. Это перестановка, а не разные направления.

## concepts-board-desktop.png
- **Один skeleton:** три идентичные `rounded-2xl` карточки в ряд — типичный «pricing/feature grid».
- **Card-grid thinking:** доска = 3 равные карточки, единственный визуальный приём.
- **Accent без причины:** синие ссылки «Открыть направление» — стандартный SaaS-акцент, не из бренда.
- **Одинаковый radius:** все карточки одного скругления → шаблонность.
- **Переименовываемость:** уберите заголовок — это карточная страница любого продукта.

## product-portal-desktop.png
- **Sidebar generic:** тот же левый навигационный столбец, что и в двух других направлениях, — «AI dashboard» из коробки.
- **Card-grid:** hero-карточка + «портал»-карточка + две карточки внизу (награда, checkpoint) — сетка контейнеров.
- **Accent без бренда:** синий `#4c8dff` primary + синий glow. Синий выбран как «дефолтный tech-акцент», а не из route/green-signal ДНК прелендинга.
- **Одинаковые материалы:** все поверхности — один тёмный surface + одна тонкая рамка; нет разных материалов (стекло/данные/свет).
- **Lucide как identity:** play/target/lock/sparkles/flame — визуальный язык держится на icon library, а не на signature object.
- **Path не самостоятельный объект:** «портал» — это горизонтальный ряд `rounded-2xl` node-плиток с иконками внутри рамочной карточки. Это виджет, а не предметная luminous route из прелендинга. Никакого ощущения «портала».
- **Alex не встроен:** сообщение Alex — отдельная маленькая карточка внизу с абстрактным силуэтом, приклеенная сбоку, а не часть композиции.
- **Rank generic:** гексагональный emblem — ровно тот «generic hexagonal rank», что запрещён.
- **Переименовываемость:** замените слова — это дашборд любого курса/SaaS. «Portal» не выглядит порталом.

- **Один материал/radius:** те же `rounded-2xl` контейнеры.
- **Path:** горизонтальный скролл плиток внизу — снова виджет, не объект.
- **Переименовываемость:** типичное мобильное приложение-дашборд.

## Итоговые причины отклонения (сводно)

1. **Один skeleton на все три** — направления не структурно разные.
2. **Card-grid как основа мышления** — всё есть контейнер с рамкой.
3. **Sidebar generic** — идентичный «AI dashboard» столбец во всех.
4. **Accent без брендовой причины** — синий как дефолт, а не green route/signal из прелендинга.
5. **Одинаковые материалы и radius** — нет иерархии поверхностей; всё `rounded-2xl` + одна рамка.
6. **Lucide-иконки вместо идентичности** — визуальный язык держится на icon library.
7. **Нет signature object** — path не стал самостоятельным предметным объектом (это node-виджет).
8. **Alex Curie не встроен** — приклеен карточкой, не часть композиции.
9. **Mobile = сложенный desktop** — ни одной mobile-first трансформации.
10. **Любой из экранов переименовывается в произвольный SaaS/LMS** — нет продуктовой и брендовой неповторимости.
11. **Нет связи с прелендингом** — ни navy-глубины, ни luminous route, ни green/cyan signal, ни chaos→system, ни монументального объекта.
