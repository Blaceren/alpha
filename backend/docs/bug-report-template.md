# Bug Report Template

## Title

Short summary of the issue.

## Severity

Choose one:

- blocker
- major
- minor
- polish

## Role/account

Example: `user@test.com`, real tester email, admin, support, mentor, moderator, news editor.

## Page

URL or page name.

## Steps to reproduce

1. ...
2. ...
3. ...

## Expected result

What should happen.

## Actual result

What happened instead.

## Screenshot/video

Attach screenshot, video, or visual QA filename if available.

## Browser/device

Browser, OS, viewport/device, and whether light/dark theme was used.

## Related feedback ID

Admin feedback ID or link, if the tester submitted it through `/feedback`.

## Status

Open / triaged / in progress / fixed / verified / won't fix.
